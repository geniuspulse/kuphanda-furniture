# Kuphanda Furniture

Custom-made office & home furniture in Lilongwe, Malawi.

## About

We custom-make high quality office furniture, boardroom tables, office cabinets, hardwood doors, beds, wardrobes, school desks, and church benches. Made in Malawi using premium local hardwood.

**Showroom:** Matope House Complex, Shops 3 & 4, Likuni, Lilongwe  
**Phone/WhatsApp:** 0885644306 / 0998757095  
**Facebook:** [facebook.com/kuphandafurniture](https://www.facebook.com/kuphandafurniture)

## Tech Stack

- Next.js 14 (App Router)
- React 18
- JSON-based product data
- WhatsApp ordering integration
- Admin panel with auth
- Blog with Markdown

## Getting Started

```bash
npm install
npm run dev
```

Visit `http://localhost:3000`

## Customization

- **Products:** Edit `data/products.json`
- **Settings:** Edit `data/settings.json`
- **Blog posts:** Add Markdown files to `content/blog/`
- **Theme:** Edit `template.config.json`

## Deployment

Deploy to Vercel:

```bash
npm run build
vercel deploy
```
